# Quick Start Guide

## Getting Started in 3 Steps

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Run the Application
```bash
python app.py
```

### Step 3: Access the Platform
Open your browser and go to: `http://localhost:5000`

## First Time User Guide

### 1. Create an Account
- Click "Sign Up" in the navigation bar
- Enter your email, password, and full name
- Click Submit

### 2. Explore Learning Resources
- Navigate to "Resources" page
- Filter by category or difficulty level
- Click "Start Learning" on any resource

### 3. Try Interactive Tools
Go to the "Learn" page and try:

**Concept Explanation:**
- Type "Neural Networks" or "Machine Learning"
- Click "Explain" to get detailed explanations

**Code Generation:**
- Type "Linear Regression" or "Neural Network"
- Select Python or JavaScript
- Click "Generate Code"

**Visual Learning:**
- Click on visualization buttons to see interactive diagrams

**Audio Lessons:**
- Type or paste any learning content
- Click "Generate Audio"
- Listen or download the audio file

### 4. Track Your Progress
- Visit the "Profile" page
- View your learning statistics
- See achievements and recent activity
- Get personalized recommendations
